# Ma Muscu 💪

Web app de suivi de musculation (un seul fichier `index.html`, aucune installation).

- Séances modifiables : exercices, séries, répétitions, temps de repos, notes
- Mode séance : saisie kg / reps par série, pré-rempli avec ta dernière perf, minuteur de repos automatique (vibration + bip)
- Progrès : records, 1RM estimé, courbe de progression par exercice, volume
- Historique, export / import JSON des données
- Fonctionne hors-ligne et s'installe sur le téléphone (« Ajouter à l'écran d'accueil »)

## Programme par défaut (4 jours)

| Jour | Séance |
|------|--------|
| Lundi | Pecs / Triceps |
| Mardi | Dos / Biceps |
| Jeudi | Jambes |
| Vendredi | Épaules (+ abdos) |

## Lancer

Ouvre `index.html` dans le navigateur, ou active GitHub Pages (Settings → Pages → branche) pour l'avoir sur ton téléphone.
Les données sont stockées localement dans le navigateur : pense à exporter de temps en temps.
